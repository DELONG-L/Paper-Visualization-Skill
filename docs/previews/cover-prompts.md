# Cover prompts

Created with the built-in ImageGen tool. The prompts below establish the composition and localization, then apply the final regular book-serif typography in English and upright Songti in Chinese. The original palette, illustration and open margins are preserved. The covers are conceptual illustrations. README preview screenshots are captured from the running example and are not generated images.
