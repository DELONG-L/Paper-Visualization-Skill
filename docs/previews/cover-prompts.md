# Cover prompts

Created with the built-in ImageGen tool. These prompts describe the current covers: a new English composition, a typography refinement, and Chinese localization. Typography uses a restrained sans-serif treatment with open margins. The covers are conceptual illustrations. README preview screenshots are captured from the running example and are not generated images.

All typography is straight and unrotated.
